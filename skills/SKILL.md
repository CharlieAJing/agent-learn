# 知识学习

## 模式选择

读取并遵循 [思考原则](references/thinking-principles.md)，按用户意图选择并读取对应模式指南。

| 模式与指南 | 职责 |
| --- | --- |
| [资料生成](references/material-generation.md) | 生成完整学习资料及配套问答 |
| [学习反馈与修订](references/dialogue.md) | 解答学习问题 |

沿用已确认的保存位置与授权范围。

## 向用户提问

本节适用于澄清、决策和确认；学习性提问遵循资料生成中的 [学习问答](references/material-generation.md#问答) 要求。

- **附带建议**：需要用户决定时，提供推荐、依据、代价和备选。
- **独立问题**：每批不超过 4 个，每问附建议及理由。
- **依赖问题**：展示依赖、各环节建议和整体路径；按已明确确认的部分推进，前提变化时重评下游，分支过多时先确认前提。
- **确认范围**：说清本次需要确认什么，不把局部确认扩大为整套批准。
- **复用结论**：沿用已确认决定和有效授权，不重复询问。

## 表达要求

- 用准确、**简洁**、**易懂**的中文表达，每段讲清一个要点。关键术语或条件可加粗。
- 标题和列表项先写读者要找的重点。年份用于定位时，“标题（年份）”；需要按时间查找时，才把时间放在开头。
- 学习资料、配套问答和对话答疑默认不举例。默认不举例说明。案例、算例和为说明公式而设的示意数据均按此规则处理。
- 外文材料译为中文，保留必要原文。专业术语首次出现时用一句话解释。英文缩写首次出现时标明英文全称，按需附中文名，后文使用缩写。
- 提建议时说清怎么做、何时适用，按需说明如何判断成效或发现失败。
- 按信息关系选直观易读的形式。并列要点用列表，同维度比较用表格，简单顺序用步骤，数据流转、分支或回路优先用流程图，结构关系用示意图，变量关系用公式或数据图。
- 图表呈现关键关系，文字补充原因、条件和例外。选图、制图或排版笔记时，查阅[图表与排版](references/material-generation.md#图表与排版)。

## 审美直觉

- **秩序**：整体与局部各得其位，层次分明、边界清晰的秩序感。
- **流畅**：句子读着顺，前后意思接得上，换到下一段也能跟上思路。
- **直观**：重点鲜明、化繁为简的清晰感。
- **简洁**：言简意足、恰到好处的美感。
