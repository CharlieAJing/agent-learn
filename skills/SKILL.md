# 知识学习

## 模式选择

读取并遵循 [交互规范](references/interaction.md) 与 [思考原则](references/thinking-principles.md)，按用户意图选择并读取对应模式指南。

| 模式与指南 | 职责 |
| --- | --- |
| [资料生成](references/material-generation.md) | 生成完整学习资料及配套问答 |
| [学习反馈与修订](references/dialogue.md) | 解答学习问题 |

沿用已确认的保存位置与授权范围；

## 表达要求

- 语言准确、**简洁**、**易懂**。
- 每段直接讲清一个知识点。
- 正文不设案例，用户答疑不受影响。
- 外文材料**译为中文**，保留必要术语原文。
- 章节标题简短（概念 / 工作原理 / 使用场景）。
- 专业术语首次出现时，用一句话解释。
- 英文缩写首次出现时，注明英文全称，必要时附中文名称，如“大语言模型（Large Language Model，LLM）”；后续可直接使用缩写。
- 提建议时，尽量说明：明确动作；适用或触发条件；完成标准、观察方式或失败信号。
- 加粗突出关键术语或条件，`==高亮==` 标记核心结论。强调保持少量，同一处选一种方式。
- 按信息关系选择表达：比较用表格；涉及数据流转、分支或回路的过程优先流程图，简单顺序操作用步骤；结构与关系用示意图；变量关系用公式或数据图。
- 图表突出关键关系，文字补充原因、条件和例外，避免逐项复述；以帮助理解为准，够用即止。
- 表格内的双链别名写作 `[[笔记\|别名]]`。交付前检查每列都有表头，且各行列数与表头一致。
- 现成图 > 外部图 > 自绘图；
- 自绘时，简单关系用纯文本，其余按需选用 PlantUML 或 Mermaid。两者均适合优先 PlantUML；需要自由布局或图片标注时可用 Excalidraw。

## 审美直觉

- **秩序**：整体与局部各得其位，层次分明、边界清晰的秩序感。
- **流畅**：行文自然、衔接顺畅的流畅感。
- **直观**：重点鲜明、化繁为简的清晰感。
- **简洁**：言简意足、恰到好处的美感。
