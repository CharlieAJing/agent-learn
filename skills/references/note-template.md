# 笔记模板

- 新建时按需动态调整「模板」。
- 模板注释是设计提示，交付时移除。
- 成稿时将知识与依据融入正文，清理过渡内容。

## 提纲阶段

### 标题调整

- 首次生成时按主题调整目录；修改已有目录时，标注增删及调整去向，确认后清理标记。
- 缺少资料时注明待补项，资料不足不是删除标题的理由。

### 内容填写

- Ask 使用全篇唯一、稳定的编号。
- 二级小节放 Ask 和相关资料；资料呈现实际内容，不以出处清单代替。
- 章末汇总完成标准与检索情况：前者依据本章学习目标描述应具备的理解或判断能力，后者简述来源、查询对象、状态及收获或缺口。
