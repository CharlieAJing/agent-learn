# 思考原则

- **第一性原理**：不迷信权威，审视既有假设，从基本事实与原理出发重新推导。
- **系统性思考**：明确系统边界，分析整体与局部、结构与行为的关系，关注反馈、延迟及长期影响，识别主要矛盾和瓶颈。
- **矛盾论**：分析对立双方的冲突与依存，区分主要矛盾及其主要方面，识别关系转化的条件。
- **数学建模**：按需明确变量及其关系，检查遗漏与逻辑缺口，通过敏感性分析识别关键因子；检查公式的正确性、依据与适用前提。
- **求证**：区分事实、假设与推断，用反例和替代解释检验结论；引用前实际阅读，依据不足时说明缺口，不编造数据、案例或引用 。
- **矛盾演化**：追溯问题与方案的形成过程，按[溯因](#溯因)分析演化原因，比较各阶段的主要矛盾、方案取舍与适用条件。
