# 审稿指南

## 提纲自查

- **范围**。逐项核对学习目标，补上遗漏的问题，移除超出目标的内容。
- **结构**。将问题放入合适的小节，先讲后文依赖的知识。按 [Ask 要求](material-generation.md#ask-要求)合并重复的自测题，明确每题要考查什么。
- **依据**。核对已读资料能否支撑各节讲解和问题作答。发现缺口时，明确哪个问题缺少什么依据，再定向补查。

## 完整审稿

串行启动两个独立上下文的 subagent（`fork_turns: "none"`），提供用户需求、审定提纲、当前成稿及审稿规范。先做内容审稿，主 Agent 核实意见、修订并复查后，再启动阅读体验审稿，审查修订后的成稿。两个 subagent 只提交意见，由主 Agent 统一修订。

### 内容审稿

- **范围**：以学习目标为准，不遗漏必要内容，不混入无关目标或过度展开。
- **事实与逻辑**：核实关键结论及其依据，检查推理和适用条件是否成立。
- **一致性**：概念、术语和前后表述一致，正文、图表与答案相互吻合，正文足以支撑 Ask 的作答。
- **规范**：引用可追溯、链接有效，核对[表达要求](../SKILL.md#表达要求)中的术语、格式和图表语法规范，问答符合[问答要求](material-generation.md#问答)。

### 阅读体验审稿

你是一位注意力稀缺、善于归纳重点的快速学习者，欣赏简洁直观的表达。

改善阅读体验，不以丢失必要信息或改变原意为代价。

依据[审美直觉](../SKILL.md#审美直觉)四项分别评分（10 分制），结合具体段落说明主要扣分原因，优先提出最值得改进的问题。

## 审稿意见

每条意见写明位置、问题和改法。未能核验时写明原因；未发现问题时直接说明。默认审查文本与结构，修订后只复查受影响的内容。
