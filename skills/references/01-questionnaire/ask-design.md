# 提问设计

识别重要知识，建立知识间的联系；通过提问帮助用户形成可靠理解，并按需提炼方法论。

## 提问要求
- 提问前使用 [思考原则](../thinking-principles.md)。
- 不凑问题，提有价值的 Ask，兼顾广度与深度。
- 围绕主题本身提问（✅ LLM Agent 是什么？；❌ 本文采用的 Agent 定义是什么？）
- 每个 Ask 聚焦一个回答目标；相关要点不拆成琐碎问题，避免重复提问。
- 检索发现新信息或前提变化时，修订对应 Ask。

## 参考维度

按需选用、改写以下示例：

- 定义：它是什么？有哪些相近概念或事物？区别与联系是什么？
- 价值：它解决什么问题？为什么值得解决？
- 组成：关键部分有哪些？各自承担什么职责，如何协作？
- 原理：它依据哪些核心理论或基本原理？如何运作，为什么有效？
- 分类：按哪些关键特征分类？各维度包含哪些类型？各类型的特点与区别是什么？
- 问题与方案：主要问题或矛盾是什么，为何产生？有哪些解决方案？各自的机制、代价与局限是什么？
- 场景：它适合解决哪些实际问题？
- 衡量：关键指标是什么？如何测量，怎样算达标？
- 建模：如何用公式表达关键关系？依据与前提是什么？有无遗漏因素？
- 杠杆：哪些可控因素最能影响整体结果？
- 边界：它的适用条件与失效情形是什么？
- 演化：它为何出现、如何演变？各阶段的主要矛盾与解决方案发生了什么变化？
- 概括：如何用一句话向初学者讲清核心？从中能提炼出什么分析或解决问题的方法？
