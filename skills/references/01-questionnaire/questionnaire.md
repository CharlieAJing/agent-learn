# 提纲

遵循 [资料检索](../research.md) 与 [学习设计](../learning-design.md)，按以下主线推进，按需往返调整：

1. 围绕学习目标初步检索，拟定大纲与基础 Ask。
2. 通过搜读、资料整理和尝试回答发现新知识，补充、修订问题与大纲，按 [资料组织](../learning-design.md#资料组织) 整合学习资料。
3. 根据资料整理各题答案。
4. 检查学习目标覆盖与知识顺序，按 [依据核验](../learning-design.md#依据核验) 逐题核验，补足缺口。

按 [Ask - Answer 示例](../learning-design.md#ask---answer-示例) 组织，统一资料置于全文末尾。
