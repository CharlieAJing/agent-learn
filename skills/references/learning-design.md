# 学习设计

## 框架使用

- 按主题调整章节框架；修改已有目录时标注**增删及去向**，确认后清理标记。
- 模板注释仅供设计，**交付时移除**。

## Ask 要求

- 提问前使用 [思考原则](thinking-principles.md)。
- 围绕学习目标与主题知识设计 Ask（✅ LLM Agent 是什么？；❌ 本文采用的 Agent 定义是什么？），**每题一个回答目标**；合并重复、琐碎问题。
- Ask 编号**全篇唯一、保持稳定**。
- 不凑问题，提有价值的 Ask，兼顾广度与深度。
- 新信息或前提变化时，**同步修订相关 Ask**。
- 通过提问引导用户**概括核心、串联知识、提炼方法论**。

## 材料要求

- 按需阅读**原文相关章节**；仅有摘要时注明可核验范围。
- 保留材料的**原意、必要上下文、适用条件与证据范围**；出处紧随对应内容，尽量链接到原文章节。
- 核验材料与内容是否**覆盖学习目标**；不足则补充，无法补足时**注明缺口并保留待补标题**。
