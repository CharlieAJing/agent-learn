# 学习设计

## 框架使用

- 按主题调整章节框架；修改已有目录时标注**增删及去向**，确认后清理标记。
- 模板注释仅供设计，**交付时移除**。
- 框架仅允许按主题增删、合并、拆分或重命名章节及小节，其余结构保持不变。


## Ask 要求

- 围绕学习目标与主题知识设计 Ask（✅ LLM Agent 是什么？；❌ 本文采用的 Agent 定义是什么？），**每题一个回答目标**，合并重复、琐碎问题。
- 按知识依赖从零基础到逐级专家展开（深度），全部答案应足以组成完整文章（广度）。
- 引导用户**概括核心、串联知识、提炼方法论**。
- 梳理资料时可动态追加 Ask；初始问题用 `A01、A02…`，追加问题用 `B01、B02…`。已有编号原样保留，按知识依赖插入问题，编号不随位置变化。
- 新信息或前提变化时，同步修订相关 Ask；Answer 沿用对应 Ask 的标识。

## 作答要求

- 围绕 Ask 给出结论与必要的解释、推理或例子；答案须独立可读，理解答案无需跳转资料。

## 资料组织

- 提纲末尾统一设置“资料”，按主题整合多个来源、跨章复用，同一知识点集中讲解。
- 资料是支撑各题作答的完整学习材料，可连续阅读、引用现成图表。

## 依据核验

- 出处随对应内容标注，尽量链接到原文章节；提纲答案可通过资料小节追溯来源，直接引文就近标注原出处。
- 逐题核验资料是否足以作答、结论是否有依据或可由其推导；不足则补充或修订资料、问题与答案，无法补足时**注明缺口并保留待补标题**。
