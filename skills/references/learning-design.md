# 学习设计

## 框架使用

- 按主题调整章节框架；修改已有目录时标注**增删及去向**，确认后清理标记。
- 模板注释仅供设计，**交付时移除**。
- 框架仅允许按主题增删、合并、拆分或重命名章节及小节，其余结构保持不变。


## Ask 要求

- 围绕学习目标与主题知识设计 Ask（✅ LLM Agent 是什么？；❌ 本文采用的 Agent 定义是什么？），**每题一个回答目标**，合并重复、琐碎问题。
- 按知识依赖从零基础到专家展开，全部答案应足以组成完整文章。
- 引导用户**概括核心、串联知识、提炼方法论**。
- 编号**全篇唯一、保持稳定**；新信息或前提变化时，**同步修订相关 Ask**。

## 作答要求

- 将作答所需的知识、依据与推理写入答案，按需补充解释和例子；删除“资料”部分后，答案仍应能独立阅读。
- 区分引文、转述与自身推断；外文引文译为中文，出处紧随对应内容并尽量链接到原文章节。
- 逐题核验：资料是否**足以作答**，答案结论是否有资料支持或可由其推导；不足则补充或修订资料、问题与答案，无法补足时**注明缺口并保留待补标题**。

### 问卷章节示例

每章按以下形式组织，问题数量按学习目标确定；资料可整合多个来源，需要论证时再添加引文。

```markdown
## {{章标题}}

### {{小节一标题}}

- **Ask 01**：{{问题}}

### {{小节二标题}}

- **Ask 02**：{{问题}}

**资料**

{{覆盖本章各题所需的知识、解释、例子与依据。}}

出处：[{{来源标题}}]({{链接}})

**答案**

**Answer 01**

{{完整回答 Ask 01，将所需知识与依据融入答案，解释必要的推理、条件与局限。}}

**Answer 02**

{{完整回答 Ask 02。}}

```
