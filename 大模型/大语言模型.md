# 大语言模型

## 概念

大语言模型（Large Language Model，LLM）是在大量文本上训练、能够处理和生成语言的模型。同一个模型可以通过不同的输入完成问答、摘要、翻译等任务，不必为每项任务单独训练。参见 [Hugging Face：语言处理与大语言模型](https://huggingface.co/learn/llm-course/chapter1/2)。

## 工作原理

以常见的自回归生成模型为例：自回归是指每一步根据已有输入和已生成内容，预测下一个词元（token，即模型处理文本的基本单位）。

```text
输入文本 → 转为词元 → 计算下一个词元的概率 → 选择并追加词元
                          ↑                      │
                          └──── 未满足停止条件 ────┘
```

例如，给出“法国的首都是”，模型根据上下文计算后续词元的概率并生成续文。这是机制示意，不是实测输出。详见 [Hugging Face：语言模型推理](https://huggingface.co/learn/llm-course/chapter1/8)。

训练通过数据调整模型参数；推理则使用训练后的参数处理输入。预训练建立基础能力，微调在此基础上继续训练。结构和训练过程分别见 [[大模型/Transformer|Transformer]]、[[大模型/训练与推理|训练与推理]] 和 [[大模型/微调与后训练|微调与后训练]]（均待学习）。参见 [Hugging Face：Transformer 的工作方式](https://huggingface.co/learn/llm-course/chapter1/4)。

## 能力与边界

| 能力或限制 | 使用时的含义 |
| --- | --- |
| 可完成多种语言任务 | 可从摘要、改写、问答等任务开始尝试 |
| 可利用输入中的示例 | 用 [[应用/提示词|提示词]] 提供任务要求与示例；该主题待学习 |
| 可能生成错误信息 | 表达流畅不能作为事实正确的依据，需要核对来源 |
| 上下文长度有限 | 不能假定模型能同时处理任意长的材料 |
| 可能带有偏见 | 需要结合实际任务检查输出，不能只看个别成功示例 |

上述能力与限制参见 [Hugging Face：语言处理与大语言模型](https://huggingface.co/learn/llm-course/chapter1/2)。实际使用时，可从正确性、响应速度和资源消耗观察效果；[[应用/效果评估|效果评估]] 主题待学习。
